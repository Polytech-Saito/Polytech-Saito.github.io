# ポートフォリオ公開サイト

HTML、CSS、JavaScriptを用いて製作するポートフォリオサイトです。
Webサイトの制作に加え、Git・GitHubによるバージョン管理や、GitHub Flowを用いた開発手法の習得を目的としています。

## 公開サイト

** URL: **[https://polytech-Saito.github.io/](https://polytech-Saito.github.io/)

GitHub Pageを利用して公開しています。

## 使用技術・開発環境
- フロントエンド... HTML5、 CSS3、 JavaScript
- 開発環境... Eclipse IDE
- バージョン管理... Git/GitHub
- 開発フロー... GitHub Flow
- ホスティング... GitHub Pages

##開発・バージョン管理
開発にはGitHub Flowを採用しています。

バージョン番号は[Semantic Versioning](https://semver.org/lang/ja/)を参考に管理し、リリース時にはGitタグとGitHub Releases採用します。

## 変更履歴・リリース番号
各バージョンの変更履歴は、Keep a Changelogを参考に'CHANGELOG.md'で管理しています。

- **[CHANGELOG.md](CHANGELOG.md)** ーバージョンごとの変更内容
- **[GitHub Releases](https://github.com/polytech-Saito/polytech-Saito.github.io/releases)**
ー リリースノート・Gitタグ・ソースコード
